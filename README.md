# Mug Ledger

A Torn City mugging dashboard. Log in with a **Full Access** Torn API key and it charts the cash you've mugged (and had mugged from you) over the last 7, 30 or 90 days, or all time.

It runs entirely in your browser: the key is only sent to `api.torn.com` and is forgotten when you close the tab. Nothing is stored on a server. Your mugging history (never the key) is saved in your browser so it only has to be pulled from Torn once; later visits fetch only new mugs.

Served with GitHub Pages from the `mug-ledger` branch.
