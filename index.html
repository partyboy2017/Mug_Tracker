Sign in with your Torn API key

Your mugging history lives in your personal logs, which only a Full Access key can read. No username or password needed.

Create one in Torn under Settings › API Keys and choose Full Access. This page runs only in your browser: the key is sent only to api.torn.com and is forgotten when you close the tab, unless you choose to stay signed in. Your mugging history is saved in this browser so it only has to be pulled from Torn once.

Ask each player to create a Custom key in Torn under Settings › API Keys with only the user › log selection, named something like "Mug Ledger admin", and send it to you.
